# 通信协议

| 资源                                                                                          | 用途                                                                  |
| --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [Bosch CAN 协议资料](https://www.bosch-semiconductors.com/products/ip-modules/can-protocols/) | 查 CAN 2.0 和 CAN FD 的协议资料，核对帧格式、总线仲裁及错误处理机制。 |
| [NXP I²C 总线规范 UM10204](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)                | 查寻址、读写传输、应答、时序和电气要求，核对 I²C 总线配置与波形。     |

芯片端的外设配置和限制应结合[芯片与内核资料](/reference/mcu-and-core)查阅；设备报文中的标识符、字段和单位应查该设备的协议文档。
