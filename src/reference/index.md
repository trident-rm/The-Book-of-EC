# 参考资料

这里收录 RoboMaster 嵌入式电控开发中常用的文档、工具和手册入口，以官方资料为主。按用途进入分类页，查找所需资源。

| 分类                                              | 内容                                       |
| ------------------------------------------------- | ------------------------------------------ |
| [语言与工程](/reference/language-and-engineering) | C/C++ 语言参考、编译器、构建系统与版本管理 |
| [芯片与内核](/reference/mcu-and-core)             | STM32 型号资料与 Cortex-M 内核接口         |
| [RTOS](/reference/rtos)                           | FreeRTOS 内核文档与 CMSIS-RTOS2 接口规范   |
| [通信协议](/reference/protocols)                  | CAN 与 I²C 协议资料                        |
| [开发调试工具](/reference/tools)                  | 工具链、代码生成、烧录、调试与波形观察工具 |
| [RoboMaster 硬件](/reference/robomaster)          | 官方资料中心、开发板例程与电机产品资料     |

芯片和工具文档应与实际使用的型号、软件版本对应；赛事规则和裁判系统协议应按参赛赛季确认。
