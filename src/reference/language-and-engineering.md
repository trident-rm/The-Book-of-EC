# 语言与工程

| 资源                                               | 用途                                                                              |
| -------------------------------------------------- | --------------------------------------------------------------------------------- |
| [cppreference](https://en.cppreference.com/)       | 社区维护的 C/C++ 语言和标准库参考，用于查语法、类型、函数及其适用的语言标准版本。 |
| [GCC 手册](https://gcc.gnu.org/onlinedocs/)        | 按编译器版本查编译选项、语言扩展和实现定义行为，排查编译、链接与优化相关问题。    |
| [CMake 文档](https://cmake.org/cmake/help/latest/) | 查命令、变量、目标属性、工具链文件和 Presets，编写或维护构建配置。                |
| [Git 文档](https://git-scm.com/docs)               | 查命令参数、配置项和操作语义，处理提交、分支、合并与远程同步。                    |
