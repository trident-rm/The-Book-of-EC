# RTOS

实时操作系统（RTOS）的文档用于核对任务调度、同步、通信和内存管理的行为与调用约束。

| 资源                                                                               | 用途                                                                                            |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [FreeRTOS 文档](https://www.freertos.org/Documentation/00-Overview)                | 查内核特性、任务、队列、信号量、软件定时器及 API，确认配置项和中断上下文中的使用限制。          |
| [CMSIS-RTOS2 文档](https://arm-software.github.io/CMSIS_6/latest/RTOS2/index.html) | 查线程、事件标志、互斥锁、消息队列和定时器等统一接口，在使用 CMSIS-RTOS2 的工程中核对调用约束。 |

CMSIS-RTOS2 是 RTOS 接口规范；具体调度行为、配置和实现限制还应查工程实际使用的内核文档。
