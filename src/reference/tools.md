# 开发调试工具

| 资源                                                                                  | 用途                                                                               |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [Arm GNU Toolchain](https://developer.arm.com/Tools%20and%20Software/GNU%20Toolchain) | 获取 Arm 交叉编译工具链，裸机 Cortex-M 工程通常使用 `arm-none-eabi` 目标的版本。   |
| [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html)               | 配置 STM32 引脚、时钟和外设，并生成初始化代码。                                    |
| [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html)             | 获取 STM32 C/C++ 集成开发环境，用于编辑、构建和调试工程。                          |
| [STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html)     | 通过调试接口或芯片 Bootloader 支持的接口连接设备，读写、校验存储器并配置选项字节。 |
| [Keil Arm 工具手册](https://www.keil.com/support/man_arm.htm)                         | 查 µVision、编译器和链接器的使用说明，核对工程配置及编译链接选项。                 |
| [OpenOCD 手册](https://openocd.org/doc/html/)                                         | 查调试探针与目标芯片配置、Flash 烧写命令和 GDB 连接方式。                          |
| [GDB 文档](https://sourceware.org/gdb/documentation/)                                 | 查断点、观察点、寄存器、内存和远程调试命令，定位程序运行中的问题。                 |
| [SEGGER J-Link](https://www.segger.com/products/debug-probes/j-link/)                 | 查调试探针支持情况，并获取 GDB Server、Ozone 和 RTT 等配套工具。                   |
| [VOFA+](https://www.vofa.plus/)                                                       | 接收串口等接口的数据并观察实时波形，用于检查传感器数据和控制变量。                 |
