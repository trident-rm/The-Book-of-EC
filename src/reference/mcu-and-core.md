# 芯片与内核

| 资源                                                                                                             | 用途                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [STM32 产品与资料入口](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html) | 按实际芯片型号进入产品页，查数据手册、参考手册和勘误，确认引脚、电气限制、外设行为与已知问题。                 |
| [CMSIS-Core 文档](https://arm-software.github.io/CMSIS_6/latest/Core/index.html)                                 | 查 Cortex-M 的内核寄存器访问、中断控制器 NVIC、系统定时器 SysTick 和启动代码接口，并跳转到对应内核的用户指南。 |

数据手册用于确认具体型号的参数与限制，参考手册用于查外设功能和寄存器；勘误中的问题还需核对适用的芯片修订版本。
