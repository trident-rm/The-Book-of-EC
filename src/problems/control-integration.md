# 控制与联调

| 现象                 | 首要观测                               | 排查边界                                 |
| -------------------- | -------------------------------------- | ---------------------------------------- |
| 电机不转或方向异常   | 供电、使能、原始反馈、控制量和实际输出 | 指令、反馈方向与执行器输出               |
| 机构抖动、超调或发散 | 原始反馈、采样周期、饱和、负载和控制量 | 采样、控制器、执行器中哪一层首先偏离预期 |
| 传感器读数跳变或漂移 | 原始数据、供电、标定、时间戳和滤波延迟 | 硬件采样、驱动解析与状态估计             |
| 单模块正常但整机异常 | 各层输入、解析结果、单位、控制量和输出 | 跨模块接口、时序和坐标约定               |
