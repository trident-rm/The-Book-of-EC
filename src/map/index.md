# 学习图

学习图是全书的正文目录。每个节点对应一个可以独立学习或完成并验证的单元；箭头从先修节点指向后续节点，学习后者前应先掌握前者。

选择节点可查看摘要、直接先修、直接后续和正文入口。图内搜索匹配节点名称、摘要和 ID，只改变当前视图，不改变节点之间的关系。
